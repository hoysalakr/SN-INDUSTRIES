# SN Industries Mysuru - Static Website

Files:
- index.html
- style.css
- script.js

## Run locally
Double-click index.html or use VS Code + Live Server.

## Publish free with GitHub Pages
1. Create a public GitHub repository.
2. Upload all three files to the repository root.
3. Go to Settings -> Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select branch `main` and folder `/ (root)`.
6. Save.
7. Open the GitHub Pages URL shown by GitHub.

## Before publishing
- Replace the text logo in index.html with the real company logo if desired.
- Review all company claims and product descriptions.
- Replace/add real product images if desired.
- Test phone, email and Google Maps links.
- The enquiry form currently opens the visitor's email application using `mailto:`.
  For server-side form submissions, connect the form to a form backend such as Formspree, Web3Forms, or a Cloudflare Pages Function.

## Custom domain
GitHub Pages can use a domain you own, but the domain itself is normally purchased separately.
